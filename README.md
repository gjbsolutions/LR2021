Micropython Examples for Semtech LR2021

Hardware: esp32c3 supermini & NiceRF LR2021 module

3.3V MCU  -->  VCC LR2021
GND MCU   -->  GND LR2021
PIN GPIO04 MCU  -->  SCL LR2021
PIN GPIO05 MCU  -->  MISO LR2021
PIN GPIO06 MCU  -->  MOSI LR2021
PIN GPIO07 MCU  -->  NSS LR2021
PIN GPIO02 MCU  -->  RST LR2021
PIN GPIO03 MCU  -->  BUSY LR2021
PIN GPIO10 MCU  -->  DIO9 LR2021
